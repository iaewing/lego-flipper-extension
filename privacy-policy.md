Privacy Policy for MXXXXX Search Reverser Extension

This Privacy Policy describes how the MXXXXX Search Reverser browser extension ("the Extension") handles your information. Because the Extension operates entirely within your browser and does not transmit any data to external servers, we adhere to a policy of No Data Collection.

1. Data Collection

The Extension does not collect, store, transmit, or share any personal user data or usage information.

No User Accounts: The Extension does not require or use any form of user account, login, or registration.

No External Communication: The Extension does not connect to any servers operated by the developer for data storage, analytics, or tracking.

No Third-Party Services: The Extension does not integrate with or send data to any third-party analytics, advertising, or tracking services.

2. Information Accessed and Processed Locally

The Extension is designed to perform a single, specific function entirely within your web browser when visiting websites matching the pattern *://*.marstoy.com/*.

Data Accessed: When active, the Extension reads the visible text content (the Document Object Model or DOM) of the Marstoy website pages.

Data Processing: The Extension locally searches the text content for patterns matching "M" followed by five numeric digits (e.g., M12345).

Functionality: If a match is found, the numeric digits are reversed, and the original text is replaced with a clickable link. The destination of this link is a search query on the official LEGO® product site (https://www.lego.com/). This operation is completed entirely within your browser and does not involve data transfer to the developer.

3. Permissions

The Extension requires the following permission, which is strictly limited to ensure minimal intrusion:

Host Permission (*://*.marstoy.com/*): This is required solely to inject the content script (flipper.js) into pages on the Marstoy domain so it can perform the local text search and link replacement function described above.

4. Changes to This Policy

We may update this Privacy Policy from time to time. We will notify you of any changes by posting the new Privacy Policy within the extension's store listing.

5. Contact Information

If you have any questions or concerns regarding this policy, please contact us through the developer contact channel provided on the extension's listing page.
